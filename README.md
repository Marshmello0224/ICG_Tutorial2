# ICG_Tutorial2

I chose the hologram shader mainly because it seemed like an interesting and complex shader to learn.

I mainly changed the smoothness in the shadergraph to X6.27, as well as the colours and I modified the transparency, the fresnel power, line speed, and line frequency.

I mainly wanted to create a more plastic, smooth looking hologram.
